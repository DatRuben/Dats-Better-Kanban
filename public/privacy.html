Dat's: Better Kanban

Privacy Policy

Overview

Dat's: Better Kanban is a project-management application designed to let users organize projects while retaining ownership of their project data.

Google Drive Access

Dat's: Better Kanban requests limited Google Drive access using the drive.file permission. This access is used for files created or used by Dat's: Better Kanban in order to save and load project data.

Project Data

Dat's: Better Kanban is designed without a central database containing users' Kanban project data. Project persistence uses the user's own Google Drive.

Authentication

Dat's: Better Kanban does not collect or store Google account passwords. Google authorization is performed through Google's OAuth services.

OAuth access tokens are temporary and are not intentionally stored in Dat's: Better Kanban project files.

Data Sharing

Dat's: Better Kanban does not sell Google user data. Google Drive access is used to provide the application's project-storage functionality.
